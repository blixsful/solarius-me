# Solarius ME
![SolME running MINIX 1.5](https://commons.wikimedia.org/wiki/Special:FilePath/SolME_running_MINIX_1.5.png?width=800)
Solarius Machine Emulator (SolME) is a lightweight software emulator designed to replicate legacy computer hardware. The platform provides low-overhead instruction set simulation for historical x86 microprocessors, including the 16-bit Intel 8086 and the 32-bit Intel 80386.
